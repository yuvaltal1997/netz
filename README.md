<h1 align="center">נץ</h1>
<p align="center"><b>מקבלים החלטות חכמות. מצילים זמן</b></p>

**נץ** היא מערכת לניתוב מטופלים מאמבולנס של מד״א למיון המתאים ביותר. המערכת שוקלת שלושה דברים: זמן הנסיעה, העומס במיון, ומידת ההתאמה של בית החולים לתלונה של המטופל.

**לצפייה באפליקציה:** https://USERNAME.github.io/netz/
(יש להחליף את `USERNAME` בשם המשתמש ב-GitHub)

## איך משתמשים
1. בוחרים רמת דחיפות ותלונה עיקרית.
2. המיקום נלקח מה-GPS. אם אין GPS, בוחרים עיר מהרשימה.
3. המערכת מציגה את היעד המומלץ: זמן עד קבלה, שעת הגעה משוערת, הסבר להמלצה וכפתורי ניווט ל-Waze ול-Google Maps.
4. לחיצה על שורה בטבלה בוחרת יעד אחר. "פאנל סימולציה" מאפשר ליצור עומס חריג בבית חולים ולראות איך ההמלצה משתנה.

## עיקרי האלגוריתם
- הציון משקלל קרבה, עומס והתאמה. המשקל של כל אחד תלוי ברמת הדחיפות.
- בטראומה או באירוע לבבי בדחיפות קשה או קריטית, המערכת עוקפת מיון עם מענה חלקי אם יש מרכז מתאים במרחק של עד 20 דקות נוספות.
- מיון מוגבל, שאין בו מיון כללי מאומת, לא מומלץ בדחיפות גבוהה.
- ההמלצה לא קופצת בגלל שינויים קטנים בעומס: נדרש פער של 3 נקודות לפחות כדי להחליף אותה.
- אם אין מיקום, לא מוצגת המלצה, כדי לא לנתב לפי מיקום שגוי.

## חיבור ל-Google Maps (אופציונלי)
בלי מפתח, זמני הנסיעה הם הערכה לפי מרחק. כדי לקבל זמני נסיעה לפי התנועה בפועל, לוחצים על כפתור ההגדרות ומדביקים מפתח API של Google עם Routes API פעיל. המפתח נשמר רק בדפדפן של מי שהזין אותו. **אין לשמור מפתח API בקבצים של המאגר.**

## טכנולוגיות
HTML ו-JavaScript, ‏Tailwind CSS, ‏Leaflet עם מפות OpenStreetMap, אייקונים של Lucide, ו-Google Routes API (אופציונלי).
